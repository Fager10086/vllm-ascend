  一、🔴 CRITICAL 级别发现（9 项）

  【C-01】pickle.loads() 反序列化共享内存数据 — 任意代码执行

  - 文件： mindie_llm/utils/layerwise/share_memory.py:79
  - 问题： pickle.loads(byte_data) 反序列化来自 /dev/shm/llm_share_memory_<pid>
  的数据。POSIX 共享内存对同用户进程可读写，攻击者可注入恶意 pickle payload 实现
   任意代码执行。
  - 修复： 用 json.dumps()/json.loads() 替代 pickle；若需二进制效率使用
  msgpack。

  【C-02】torch.load() 未设置 weights_only=True — 任意代码执行

  - 文件： examples/atb_models/tests/encrypttest/encrypt.py:73
  - 问题： torch.load(local_weight_file, map_location="cpu") 内部使用
  pickle，恶意 .bin 文件可触发 RCE。
  - 修复： 添加 weights_only=True 参数。

  【C-03】Docker 镜像以 root 用户运行

  - 文件： docker/mindie_llm_ubuntu24_aarch64.dockerfile:338-339
  - 问题： 最终镜像 USER root 覆盖了之前创建的非特权用户
  HwHiAiUser，容器内所有进程以 root 运行。
  - 修复： 删除第 338-339 行，保留 USER HwHiAiUser。

  【C-04】Docker 镜像授予无密码 sudo 权限

  - 文件： docker/mindie_llm_ubuntu24_aarch64.dockerfile:252
  - 问题： echo 'HwHiAiUser ALL=(ALL) NOPASSWD:ALL' >> /etc/sudoers
  完全消除了权限边界。
  - 修复： 删除 NOPASSWD:ALL sudoers 条目。

  【C-05】C++ 不安全的 Union 类型双关 + C 风格强制转换

  - 文件： mindie_llm/text_generator/cpp/sampler/cpu_logits_handler/post_process
  ing_manager.cpp:40-44, 220-232
  - 问题： union VPtrUInt64 在 void* 和 uint64_t 之间双关是 C++
  未定义行为；同一内存地址被同时转换为
  uint16_t*、float*、uint64_t*，违反严格别名规则。
  - 修复： 使用 std::bit_cast(C++20) 或 memcpy 实现类型双关；用 reinterpret_cast
   替换 C 风格转换。

  【C-06】Shell eval 执行用户控制的命令 — 命令注入

  - 文件： examples/atb_models/examples/models/qwen2_vl/run_pa.sh:144
  - 问题： eval "$base_cmd" 中 $base_cmd 包含用户传入的 --model_path
  等参数，未经消毒。
  - 修复： 改用 bash 数组 + 直接执行，消除 eval。

  【C-07】Shell eval 执行动态拼接命令

  - 文件： examples/atb_models/tests/modeltest/scripts/mm_run.sh:94
  - 问题： eval "${run_cmd}" 执行从多个环境变量拼接的命令字符串。
  - 修复： 使用 env + 数组形式直接调用。

  【C-08】rm -rf /dev/shm/* 清除全系统共享内存 — 拒绝服务

  - 文件： scripts/set_env.sh:20
  - 问题： 无条件删除 /dev/shm/*，在多租户环境中破坏所有其他进程的共享内存。
  - 修复： 仅清理应用专属共享内存，如 rm -f /dev/shm/mindie_*。

  【C-09】Shell eval 执行文件内容 — 文件注入
